# Illustrations

Source: [unDraw](https://undraw.co) — open-source illustrations, free for personal and
commercial use with no attribution required. Extracted from the MIT-licensed
`react-undraw-illustrations` package (v2.0.3) and re-exported as standalone SVG.

unDraw's swappable accent color has been remapped from its default `#6c63ff` to this app's
primary green `#58cc02` so the artwork sits in the same palette as the rest of the UI.
